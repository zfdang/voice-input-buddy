Before installing

When the microphone driver is new or changed, installation restarts Core Audio. This briefly interrupts all system playback and recording, including calls and meetings. Save your work and finish any call or recording before continuing. Reinstalling an unchanged driver does not restart audio.

The installer requires administrator authorization. This package is unsigned and not notarized by Apple. The release app and driver use the project's fixed self-signed identity.

安装前请确认

首次安装或驱动发生变化时，安装器将重启 Core Audio，短暂中断系统全部播放和录音，包括通话与会议。 请先保存工作、结束通话或录音，再继续安装。驱动未变化的重复安装不会重启音频。

安装需要管理员授权。本安装包未签名、未经 Apple 公证；发布版 App 和驱动使用项目固定自签名身份。
