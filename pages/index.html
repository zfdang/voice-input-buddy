  1. 01

    安装并打开

    从 Release 下载 PKG，打开 Applications 中的 Voice Input Buddy。

  2. 02

    完成环境检查

    按向导授权蓝牙、输入监控和辅助功能。

  3. 03

    连接与配置

    连接遥控器并测试按键；驱动检查通过后，点击“继续”。App 自动使用 Voice Input Buddy Mic；在输入工具里选择同名麦克风，并配置语音快捷键。

  4. 04

    打开输入框，说话

    完成相应工具的向导设置和语音测试后，按住遥控器语音键说话、松开结束。使用网易叭哥说、Typeless 等点按式工具时，启用“语音键模拟 Fn 点按”，由 App 配合收音过程发送开始和结束快捷键。

TROUBLESHOOTING · 常见问题

语音正常，按键却没反应？

先检查 Karabiner-Elements 等按键工具的设备占用。

这类工具可能独占遥控器，导致语音搭子收不到按键。典型表现是普通按键无法执行已配置的动作，而蓝牙连接或语音仍然正常。默认映射中，主页键切换应用、TV 键播放／暂停、电源键退格、返回键发送 Escape。

  1. 在 Karabiner-Elements 中打开 Devices（设备），找到你的遥控器，例如“小米蓝牙语音遥控器”。
  2. 关闭这只遥控器的 Modify events，把它交给语音搭子处理。其他键盘的设置可以保留。
  3. 重新连接遥控器，或重启语音搭子，再到“按键映射”检查连接状态，测试主页键、TV 键、电源键与返回键。

若仍提示“设备被其他输入工具占用”，可重启 Karabiner-Elements 后再试；同时检查语音搭子的输入监控与辅助功能权限。
