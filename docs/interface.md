# macOS 界面与使用流程

主导航按日常使用顺序排列：

1. **设备连接**：右上角“添加新设备”；每台遥控器单独分组显示名称、图片、连接状态和增益。增益独立保存，页面不再选择语音输出设备。
2. **按键映射**：顶部用紧凑下拉框选择已记录的设备；电量与连接详情在设备连接页显示。普通硬件按键与动作、快捷键和常用语。语音设置入口跳转到输入法集成，不再滚动到按键页底部。
3. **输入法集成**：当前输入工具、语音快捷键和音频状态；微信输入法、豆包输入法、网易叭哥说、Typeless、VoiceCursor、macOS 听写与其他工具的配置向导入口；语音触发方式与按住／点按行为。
4. **权限与环境**：蓝牙、输入监控、辅助功能三项授权；虚拟麦克风驱动是否已加载，驱动信息下显示固定输出 Voice Input Buddy Mic；安装说明和设备刷新；隐私与数据处理说明。
5. **通用设置**：顶部显著的“重新运行设置向导”；语言、启动与图标显示、设置导入导出、诊断日志与版本信息。

输入法集成通过设置向导配置并验证，不读取其他应用的私有配置，也不把检测到安装当作兼容验证。VoiceCursor 有独立入口，沿用通用工具的自定义快捷键流程，未新增专用适配器。重新选择输入工具不会清除遥控器档案、增益或普通按键映射。

使用微信、豆包等系统输入法时，语音触发前会自动切入所选输入法；成功触发后不自动切回，避免打断异步识别和文本提交。需要换回其他输入法时，可手动切换。VoiceCursor 等独立工具不切换系统输入法，沿用各自的语音快捷键和文本回填流程。

## 常见问题的入口

- 系统设置开关已开、App 却认为未授权：在权限页核对状态。临时开发签名变化会使旧授权失效，需要添加当前 App 并重新授权。
- 安装驱动后没有麦克风：在权限页刷新设备，确认 Voice Input Buddy Mic 已检测到；必要时重新安装当前架构的最新 PKG，并按提示重启 Mac，使 Core Audio 重新加载驱动。
- 遥控器连不上或不识别按键：进入设备连接检查具体设备与连接状态；检查权限页输入监控授权。
- TV 键、返回键等失效但语音正常：检查 Karabiner-Elements 的 Devices，关闭这只遥控器的 Modify events，保留其他键盘设置，重连遥控器或重启语音搭子。若仍提示设备占用，可重启 Karabiner；检查输入监控和辅助功能授权。详见[官网排障](https://voice.zfdang.com/#troubleshooting)与[官方设备设置](https://karabiner-elements.pqrs.org/docs/manual/configuration/configure-devices/)。
- 有声音却无法输入：进入输入法集成，核对目标工具的麦克风、语音快捷键和按下／松开行为，再运行实际输入测试。
- 需要从头检查配置：通用设置顶部重新运行向导。该流程不清除现有硬件连接与普通按键配置。

菜单栏使用原创单色麦克风与硬件按钮轮廓，提供 1x／2x 资源；正在传输语音时改为实心。图标为 macOS 模板图像，颜色由系统适配浅色、深色及选中状态。图标脚本为 `scripts/generate-status-icons.swift`。

首次设置向导先检查权限，顶部逐项显示八个步骤：系统权限、准备设备、连接遥控器、按键测试、驱动检查、输入工具、语音测试和完成。权限检查不依赖预先选择设备；驱动检测在第 5 步自动完成，首屏只检查三项系统权限。首次使用默认跟随系统语言，第一步左下角可选择系统默认、中文或英文，选择持久保存。

第 2 步用单选圆点表示当前设备选择，四项设备均可选择。小米和两款 Google 选项可进入连接页；Siri Remote 点击继续后留在此页，显示尚未支持的提示。GY3LE 的设置入口不代表已实现协议适配；G9N9N 仍需实际连接及按键验证，不代表已完成真机验收。

Google 遥控器配对：打开 Mac 的“系统设置 → 蓝牙”，同时按住遥控器返回（Back）和主页（Home）直到指示灯闪烁，再在蓝牙列表中选择并连接。连接后按普通按键检查输入；重新配对时可先忽略原设备，不需要等待电视上的配对提示。

输入法候选框正在显示时，方向键和 Return 通常用于选词。请先选词确认或按 Escape 取消预编辑，再启动语音输入；程序不会自动发送 Escape，以免丢弃尚未确认的文字或关闭目标应用的对话框。

“添加新设备”只走设备选择、连接、按键测试和完成；输入工具的配置向导只走输入工具、语音测试和完成。两种入口都保留已有设备与按键配置。

常用语管理从按键映射进入，可将短语绑定到按键。普通原生文本框优先使用公开 AX 接口；检测到终端、Web 内容、Electron 编辑器，或文本控件不支持 AX 写入时，使用临时剪贴板与 Cmd+V。剪贴板原有各项格式仅暂存在内存，粘贴后尝试恢复；期间检测到用户复制新内容时保留新内容。安全输入、敏感控件、非终端的无法确认目标及已有文本选区会拒绝插入。只发送粘贴指令不代表目标应用已经提交文本，具体终端和编辑器仍需兼容性验收。


## 固定输出与设备增益

所有遥控器共用 Voice Input Buddy Mic（UID `BuddyMic2ch_UID`）。正常页面及向导不提供输出设备选择，
不会切到扬声器或 BlackHole；更改 macOS 默认扬声器、麦克风也不会改变此路由。
第 3 步连接设备，第 4 步测试按键，第 5 步检查驱动与固定输出。程序自动配置虚拟麦克风，
驱动已检测且输出就绪后启用“继续”，由用户点击后进入下一步；前进和返回时均停留在本页。失败时提供重试、安装说明和重启 Mac 的提示。
设备增益随各自档案保存，向导语音测试的增益只修改当前遥控器；切换遥控器不改变其他设备的增益。

## 按键长按与持续连发

小米蓝牙遥控器的新安装缺省映射：Home 单击为 Command+Tab（切换任务），TV 单击为媒体播放／暂停，OK 长按为 Command+Enter。已有安装保留已保存的映射，包括尚未设置的 OK 长按动作；主动恢复默认映射时使用这些新缺省值。

每个普通按键分别配置单击、双击和长按动作。长按可选择独立动作，或选择“持续连发”：按住约 350 毫秒后重复执行当前单击动作，松开即停止。方向键、音量键和电源键默认显示“长按：持续连发”；电源键的单击默认为删除，按住可连续删除。返回键的单击默认为 Escape，长按默认为“未设置”。其他按键也可以选择持续连发。选择普通长按动作后，该动作约在 550 毫秒时执行一次，不与连发同时生效。双击可独立配置；短按仍等待双击判定，持续按住时则转为连发，松开不再补发单击。选择“未设置”可关闭长按行为。

“允许连续快速按”用于短时间内的多次独立点按，与长按连发不同。长按设置随设备的按键映射保存，也包含在配置导入导出中。
