# 隐私边界与验证

本产品保留本地排错日志及设置，不采集使用统计、不捕获转录文本、不归档语音、不上传日志。向导步骤历史（`firstUseEvents`，上限 100 条）和排错日志仅保存在本机 UserDefaults 及本地沙盒日志文件中，不包含任何远程遥测，且不离开本机。旧统计数据模型、记录 API、统计界面及兼容清理逻辑均已移除。识别工具是否上传语音及文本，应依据所选工具的设置和政策，本产品不能代表第三方承诺离线。

自动验证包括上游 ATVV 编码、解码、会话准入与蓝牙生命周期测试，以及本项目的功能边界检查。自动化通过不证明遥控器真机兼容、目标输入法成功识别或驱动安装通过。

真实验收需要：全新权限下完整走 wizard；遥控器按住与松开；断连释放快捷键；连接/休眠恢复；输入框焦点保持；虚拟麦克风收到音频；目标 IME 和 VoiceCursor 的开始、停止和最终输入；驱动安装与卸载；确认统计、转录历史和上传入口不存在。

常用语的兼容粘贴会短暂读取并备份当前剪贴板的各项格式，在内存中保存，粘贴后尝试恢复；不把剪贴板内容或短语正文写入日志、文件或上传。期间检测到新的复制内容时保留新内容。剪贴板管理器可能观察到临时短语，因此这不是“不触碰剪贴板”的模式。系统拒绝读取或无法完整备份时不会执行替换。

## 发布与开发签名

main 自动发布 Apple Silicon / Intel 的 App 与驱动一体 PKG，以及通用卸载包。App 与驱动使用固定自签名身份，安装包未签名、未公证；应用更新还要求本项目的 Sparkle 签名。构建与源码对应关系见 [发布说明](releases.md) 和 [对应源码](source-code.md)。

开发 App 位于 `dist/Remote Buddy.app`。开发签名或路径改变后，系统授权可能失效，需在系统设置中重新选择实际构建的 App。输入监控按钮请求系统授权并打开设置；权限仍需用户开启。权限、设备及升级验收应记录针对当前构建的结果，不能复用旧版本截图或历史测试数量作为当前通过依据。
